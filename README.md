# Supermart Grocery Sales Analytics (Python & MySQL)

## 🎯 Overview
This project focuses on analyzing grocery store sales performance across different regions, product categories, and customer segments. By integrating Python data analysis libraries with a MySQL database, the project aims to help supermarket management optimize inventory, improve profit margins, and identify key revenue drivers.
